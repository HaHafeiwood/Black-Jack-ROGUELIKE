## 狀態標記

- **已實作**：目前遊戲已可觸發或使用。
- **已實作、待平衡驗證**：功能已存在，但取得節奏、價格、強度或遊玩體驗尚需驗證；不能寫成未實作。
- **已確認、待完成**：規則方向已定，但介面或內容仍未全部完成。
- **討論中**：只有設計草案，不應視為正式規則。
- **待確認／文件衝突**：無法確認最新正式決議，須保留實作現況與歧義，不自行恢復舊規則。

新增或變更的遊戲規則已確認、但程式尚未實作時，必須標記為「已確認、待完成」。只補正已實作功能的過時文件時，應標示文件同步，不可誤寫為功能未完成。本文中的「已完成」等同功能已實作，不代表已通過平衡驗證。未決定的數值、觸發時機與懲罰方式另外列入「討論中」。

最新明確確認的設計決議決定規則意圖；程式用來確認實作現況，文件用來保存決議與狀態。設計師提案不等於已核准規則。文件與程式衝突時，先區分文件過時、實作不符正式決議、設計本身的體驗問題及尚待確認，不因舊文件自行恢復已取消的限制。
