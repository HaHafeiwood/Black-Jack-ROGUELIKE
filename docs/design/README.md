# 《21 點 ROGUELIKE》設計文件

- [01-overall-design.md](01-overall-design.md)：整體設計理念、遊戲節奏、隨機性與平衡原則。
- [02-characters.md](02-characters.md)：所有玩家角色的定位、起始資源與主要玩法。
- [03-enemies.md](03-enemies.md)：所有一般敵人、事件敵人、魔王與終極魔王的設計理念。
- [04-combat-and-status.md](04-combat-and-status.md)：戰鬥、防禦、控制值、狀態與敵人成長原則。
- [05-equipment-and-blades.md](05-equipment-and-blades.md)：被動裝備、稀有度、詞條、消耗品與武士刀具系統。
- [06-events-and-economy.md](06-events-and-economy.md)：樓層結構、事件、商店、賞金、教堂與陣營系統。
- [07-magician-and-consumables-rework.md](07-magician-and-consumables-rework.md)：已實作的魔術師三階術式、花色專精、十五種消耗品附魔、工房與存檔遷移規格。

## 狀態標記

- **已實作**：目前遊戲已可觸發或使用。
- **已確認、待完成**：規則方向已定，但介面或內容仍未全部完成。
- **討論中**：只有設計草案，不應視為正式規則。

凡是只修改設計文件、尚未同步修改遊戲程式的內容，必須在相關段落明確標記為「已確認、待完成」。規則中仍有數值、觸發時機或懲罰方式尚未決定時，另外列入「討論中」，不可與待實作項目混寫。

若文件與遊戲實際行為衝突，應先確認近期修改是否尚未同步到文件；確認後再決定修正程式或更新文件。
